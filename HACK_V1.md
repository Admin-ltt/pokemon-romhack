# Pokémon Emerald Expansion Prototype v1

Base: RHH pokeemerald-expansion 1.17.1-compatible source tree.

## Included in this prototype
- Rockruff / Riolu / Mudkip starters on Emerald build.
- Rival starter families remapped to counter the new starter choices.
- Soft level caps using the existing badge cap table, with boosted EXP below the cap.
- HGSS-style expanded Pokédex.
- HGSS-style Pokémon followers.
- Gen 5-style overworld location popups.
- Time-of-day wild encounters enabled.
- Route 101 morning/day/evening/night encounter identities.
- Early-route wild encounter rebalance on Routes 101-103.
- Early trainer rebalance on Route 102.
- Oldale Mart expanded with Quick Balls, Repels and Escape Ropes.
- Small Route 102 item side-event.

The source tree is intentionally kept buildable with the normal Expansion toolchain. The supplied clean Emerald ROM is retained as the reference ROM and is not modified.
